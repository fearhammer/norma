# Norma

Исходники сайта norma-studio.ru. Проект на этапе подготовки.

## Согласованные требования

- Astro в статическом режиме: весь основной контент и метаданные находятся в готовом HTML каждой страницы.
- Без базы данных. Контент услуг и блога хранится в файлах проекта.
- Минимум клиентского JavaScript, основной контент и навигация доступны без него.
- Общие компоненты и отдельные композиции услуг по макетам Figma.
- Адаптация для телефона, планшета, компьютера и промежуточных ширин.
- Фото, градиентные подложки и HTML-текст — отдельные слои. Градиент следует за областью текста; кадрирование фото настраивается для разных экранов.
- Одна закреплённая шапка: повторы меню в Figma обозначают её положение при прокрутке.
- Уникальные title, description, canonical, Open Graph; семантические заголовки, подходящие структурированные данные, sitemap и robots.txt.
- Alt подготавливается с учётом самого изображения и его контекста; декоративные изображения получают пустой alt.
- Тексты FAQ, отзывов и форматов сотрудничества будут заменены после вёрстки.
- Публикация на действующий домен пока не настроена. Перед настройкой нужно уточнить услугу и тариф хостинга REG.RU.

## Текущий этап

Сверстаны шапка, первый экран и текстовая часть блока «Какие сайты делаем». Остальные секции макета ещё не реализованы. Ссылки на другие разделы и кнопки консультации пока ведут на существующий сайт; окончательные адреса и обработчик формы предстоит подключить.

Контент: `src/data/website-service.ts`. Общие стили: `src/styles/global.css`. Шаблон страницы: `src/pages/services/razrabotka-saitov.astro`.

### Шрифты и изображения

Suisse Intl хранится локально в `public/fonts`: Book (350), Regular (400), Medium (500), SemiBold (600). CSS-вес 350 различает Book и Regular. Веб-страница загружает только используемые начертания; Regular предварительно загружается.

Предоставленные фотографии сохранены в `src/assets/photos`. Их исходные файлы не изменены. В `ServiceHero.astro` используется широкий кадр из Figma для компьютера и `hero-mobile.jpg` для телефона. Нужный кадр выбирает HTML-элемент `picture`, без JavaScript. Astro создаёт WebP нескольких размеров при сборке. Градиенты находятся только в CSS.

### Локальная работа

Установить Node.js и pnpm, затем выполнить:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Проверка готового статического сайта:

```sh
pnpm build
pnpm preview
```

Для запуска в ограниченной среде можно задать `ASTRO_TELEMETRY_DISABLED=1`.

Предпросмотр: `http://127.0.0.1:4321/services/razrabotka-saitov/`.

Черновая сборка по умолчанию содержит `noindex`. Только для законченной основной версии при сборке необходимо установить `PUBLIC_INDEXABLE=true`. Карта сайта, robots.txt и структурированные данные ещё не добавлены. Автоматическая публикация не настроена; отправка исходников в GitHub не меняет действующий сайт.
